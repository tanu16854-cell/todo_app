# TODO App

A simple TODO application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed or uncompleted
- Save tasks using LocalStorage
- Task count
- Press Enter to add a task
- Simple and responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start adding and managing your tasks.

## Project Highlights

- Beginner-friendly TODO application
- Tasks are dynamically created using JavaScript
- Task data persists after page refresh
- Clean and simple user interface
- Source code maintained using Git and GitHub
